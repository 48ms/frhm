## HIGH: Hard Gate (absolute)

### [1] R-02: Em dash (, ) di teks yang dilihat pengguna
- **Lokasi:** `components/calendar/calendar-export-modal.tsx:119`, `components/calendar/calendar-export-pdf.tsx:2,39,41`
- **Bukti:** `# Jadwal Konten: ${clientName}` dan `<Text>Jadwal Konten: {clientName}</Text>`
- **Dampak:** Em dash muncul di judul file export Markdown + judul PDF yang dibaca klien.
- **Fix:** ganti `, ` dengan `:` atau `,`. Contoh: `Jadwal Konten: ${clientName}`.

### [2] R-17: Angka tanpa sumber nyata (data fiktif)
- **Lokasi:** `app/admin/calendar/calendar-client.tsx:398,400,473`
- **Bukti:**
  - `18:00 – 20:30 WIB` (Peak Velocity Timeslot)
  - `TikTok & Reels Velocity Index 94/100`
  - `Recommended: 14:00`
- **Dampak:** Angka-angka ini hardcoded, bukan hasil perhitungan telemetry. Menyesatkan operator yang mengira itu data nyata.
- **Fix:** hitung dari `post_metrics`/`analytics` bila tersedia, atau ubah menjadi label jujur (mis. "Belum ada data velocity" / `[REAL DATA]`), atau hapus kartu.

### [3] R-36: Klaim yang tidak bisa diverifikasi
- **Lokasi:** `app/admin/calendar/calendar-client.tsx:415-418`
- **Bukti:** `Ready for Dispatch` + `Meta Graph & TikTok Cloud Active` (kartu "API Connection Status")
- **Dampak:** Mengklaim koneksi Meta/TikTok aktif, padahal fakta: 0 klien punya `ayrshare_profile_key`, API Ayrshare 403 Paid Plan. Klaim ini bohong.
- **Fix:** ambil status nyata dari `client_channels` (ada/tidak channel terhubung), atau ubah jadi empty state jujur ("Belum ada akun sosial terhubung").

### [4] R-27: Kelengkapan state (empty / loading / error)
- **Lokasi:** `app/admin/calendar/calendar-client.tsx`
- **Bukti:** Ada empty state di list view (`calendar-view.tsx:431`) dan drawer draft kosong (`:702`). Tapi **tidak ada loading state** saat `useScheduledPosts` memuat, dan **tidak ada error state** bila query gagal.
- **Dampak:** Saat fetch pertama, kalender tampil kosong tanpa indikator (bisa disalahartikan "tidak ada jadwal"). Saat query error, user tidak tahu apa yang gagal.
- **Fix:** tambah loading skeleton untuk grid kalender + error state dengan sebab dan aksi ulang.

## MEDIUM: Purpose-Gate (teknik perlu alasan tertulis)

### [5] R-10: Glassmorphism melebihi dosis (cap 1-2 elemen)
- **Lokasi:** `app/admin/calendar/calendar-client.tsx`
- **Bukti:** `glass-panel` dipakai **8 kali** + `glass-card-nested` **3 kali** (kartu metric, workspace, drawer, footer). `backdrop-blur-md` juga di sub-header (`:263`).
- **Dampak:** Semua permukaan berada di lapisan frosted yang sama, hierarki hilang.
- **Fix:** pilih maksimal 1-2 permukaan yang benar-benar butuh glass (mis. sub-header control bar). Sisanya solid.

### [6] R-04: Emoji dekoratif di UI
- **Lokasi:** `app/admin/calendar/calendar-client.tsx:468`
- **Bukti:** `<span className="text-[28px]">{isDarkFlight ? "🌙" : "+"}</span>`
- **Dampak:** Emoji 🌙 sebagai hiasan sel "Dark Flight" (label yang sendiri juga fiktif).
- **Fix:** hapus emoji, pakai ikon relevan atau tanpa penanda.

### [7] R-31 / R-13: Dot status dekoratif tanpa state nyata
- **Lokasi:** `app/admin/calendar/calendar-client.tsx:617,831`
- **Bukti:** `<span className="w-2.5 h-2.5 rounded-full bg-secondary" />` di samping judul "Today's Dispatches" dan "Scheduled posts sync via the publish worker".
- **Dampak:** Dot hijau/aksen yang tidak menandai state live apa pun.
- **Fix:** hapus dot, atau hubungkan ke state nyata (mis. indikator sync yang benar-benar aktif).

### [8] R-04: Ikon generik AI tanpa alasan tertulis
- **Lokasi:** `app/admin/calendar/calendar-client.tsx:212,349,400`
- **Bukti:** `Icons.sparkles` (tombol AI Copilot), `Icons.rocket` (kartu Scheduled Flights), `Icons.bolt` (velocity).
- **Dampak:** `sparkles` adalah ikon AI generik; `rocket`/`bolt` tidak menjelaskan kontennya.
- **Fix:** ganti dengan ikon relevan (mis. `Icons.calendar`, `Icons.list`) atau hapus. (Catatan: `Icons.bot` di `:761` sudah benar, ada `// antislop-exception R-04`.)

### [9] R-31: Stripe kiri dekoratif
- **Lokasi:** `app/admin/calendar/calendar-client.tsx:409`
- **Bukti:** `border-l-4 border-l-primary` pada kartu "API Connection Status".
- **Dampak:** Stripe warna tanpa makna status.
- **Fix:** hapus stripe, atau pakai hanya bila menandai state nyata.

## LOW: Quality Locks (konsistensi)

### [10] R-11: Radius pill berlebihan
- **Lokasi:** `components/calendar/calendar-view.tsx` (7x `rounded-full`), `calendar-client.tsx` (banyak pill)
- **Dampak:** Hampir semua kontrol pill. Radius berhenti jadi alat hierarki.
- **Fix:** pertahankan radius konsisten: `rounded-lg` (8px) untuk kartu/input, `rounded-md` (6px) untuk tab, `rounded-full` hanya untuk status dot/pill (sesuai `frhm-patterns.md`).

### [11] R-01: Bahasa campur (ID/EN)
- **Lokasi:** `app/admin/calendar/calendar-client.tsx:227,236`
- **Bukti:** "Hasilkan ide satuan (SPARK)", "Buat kalender sebulan sekaligus" (di UI berbahasa Inggris lain).
- **Dampak:** Nada tidak konsisten.
- **Fix:** pilih satu bahasa untuk seluruh halaman (ikut mayoritas: EN), atau lokalisasi menyeluruh.

### [12] R-16: Klaim buzzword
- **Lokasi:** `app/admin/calendar/calendar-client.tsx:202`
- **Bukti:** Headline "Multi-Channel Dispatch Schedule" (bukan buzzword, tapi "Studio AI Prediction" di `:762` mendekati).
- **Dampak:** Ringan; hanya perlu konsistensi bahasa.
- **Fix:** opsional, samakan gaya dengan sisa halaman.

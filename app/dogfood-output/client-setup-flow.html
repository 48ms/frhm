Client Setup bukan kalender. Setup = gerbang kerja.

Pain lo (planning, produksi, posting, evaluasi) hidup di tab lain. Setup yang bikin tab itu punya konteks brand, channel, dan skill yang boleh jalan. Tanpa gerbang ini, calendar/production/analytics tetap kosong atau generic.

1. Alur sekali pas client baru

1 Onboard (niche, audience, USP)
2 Generate 5 file fondasi
3 Pilih pack + channel
4 Cek siap / belum
5 Kerja harian di tab lain
Setup tab isi ini
Konfigurasi, bukan eksekusi.
  • File: brand-profile.md → voice.md → audience.md → social-strategy.md → content-pillars.md
  • 7 stage repo: Foundation → Plan → Create → Media → Publish → Grow → Measure
  • Skill aktif per client (status belum / jalan / selesai)
  • Channel: belum / terhubung / gagal
  • Guardrail + ground truth repo (jangan publish tanpa konfirmasi)
Bukan isi Setup
Itu tab operasional, setelah gerbang hijau.
  • Kalender 2 minggu + campaign/event overlay → Content Calendar
  • Ide → script → shoot → edit → caption → approve → Production
  • Apa yang harus post hari ini / minggu ini → Pipeline + Publish
  • Konten mana yang perform + kait sales → Analytics

3. Pain lo masuk di mana

Planning masih manualSetup cuma nyalain stage Plan + cek file pillars. View satu layar = tab Calendar, bukan Setup.
Produksi paralel + urgentSetup nentuin skill Create/Media yang boleh jalan. Tracking status ide→approve = Production + client_skills.
Lupa postingSetup ngecek channel terhubung. “Hari ini harus post apa” = Calendar/Publish. Reminder belum ada di kode.
Analytics belum jadi kesimpulanSetup nyalain Measure. Hubungan campaign↔sales belum ada tabel. Jangan janji ROI di Setup.

4. Urutan bangun (biar ga nyampur)

  1. Setup: checklist 5 file + 7 stage + channel + skill aktif. Render data yang sudah di-query.
  2. Generate fondasi dari UI (ganti run_skill.py).
  3. Calendar view: slot dari Plan + overlay promo/event.
  4. Production board: status mesin ide → siap post.
  5. Hari ini / minggu ini + reminder.
  6. Analytics → kesimpulan. Sales link belakangan (schema baru).

Future-proof-nya di gerbang (file + skill + channel), bukan di janji dashboard all-in-one di tab Setup.
